💡 When to Use Each Empty State

  • No Search Results: User searched but nothing matched their query
  • No Filter Results: User applied filters but no content matches
  • Error State: Something went wrong (API error, network issue, etc.)
  • Compact Variant: For smaller UI areas like sidebars or cards
  • Inline Variant: For sections within a page (no border/background)

✅ Best Practices Implemented

  • Clear Messaging: Explains what happened and why
  • Actionable CTAs: Tells users what to do next
  • Helpful Alternatives: Provides secondary options
  • Friendly Tone: Not blaming the user, being helpful
  • Visual Clarity: Icon + text + button hierarchy
  • Accessibility: Proper ARIA roles (status, alert, live regions)
  • Responsive: Full-width buttons on mobile, centered on desktop
