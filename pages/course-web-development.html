What You'll Learn

  • Build 16+ real-world projects including blogs, e-commerce sites, and web apps
  • Master HTML5, CSS3, Flexbox, Grid, and responsive design
  • Learn JavaScript, ES6+, DOM manipulation, and async programming
  • Build backends with Node.js, Express, and MongoDB
  • Create modern frontends with React and React Hooks
  • Deploy web applications to production using Heroku and Netlify

Course Overview

Welcome to the Complete Web Development Bootcamp, the only course you need to learn to code and become a full-stack web developer. With over 50 hours of HD video tutorials, you'll learn the latest technologies to build ANY website you want.

This course is designed and taught by Dr. Angela Yu, a London App Brewery instructor with over 4 million students worldwide. We've crafted this course from the ground up to make learning web development as simple and effective as possible.

By the end of this comprehensive course, you will be fluently programming and ready to build professional-level websites and web applications. You'll even have a portfolio of 16+ projects to show to any potential employer.
